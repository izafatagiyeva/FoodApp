# Garden of flavor
## Features 🚀
* **Dynamic Content Loading:** Fetches and displays food items dynamically.
* **Category Filtering:** Easily filter dishes by tags (e.g., Breakfast, Lunch, Shakes) with a single click.
* **Clean UI:** Simple and user-friendly interface focusing on imagery and food details.

## Tech Stack 🛠️
* **HTML5:** Semantic structure of the application.
* **CSS3:** Custom styling, flexbox/grid layouts, and responsive design.
* **JavaScript (ES6+):** DOM manipulation, event handling, and data filtering logic.
